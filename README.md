# Glyde Market Maker

Open-source market making strategies for [Glyde](https://glyde.trade), built on Glyde's One API (Hyperliquid-compatible `/info`, `/exchange` and WebSocket).

The goal is the shortest path from "I want to try market making" to quotes on the book: one install, one config file, one command, with paper mode first.

Strategy designs are adapted from [Hummingbot](https://github.com/hummingbot/hummingbot) (Apache-2.0). See `NOTICE`.

Status: early development.
